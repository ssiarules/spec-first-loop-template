# Decisions

Locked decisions for this project. When a decision changes, add a new row that supersedes the old one. Never rewrite a locked row.

| Date | Decision | Who decided | Why | Supersedes |
|---|---|---|---|---|
| YYYY-MM-DD | Example: staging first, production only on Owner go | Owner | Pushed is not verified | |

## How to record a decision

1. Write it in plain words, one line.
2. Name who decided it.
3. Name why, in one line.
4. If it replaces an older decision, name the older row in the Supersedes column.
